# Christian Bleeker

Personal portfolio website for Christian Bleeker, built with Next.js.

## Local development

```bash
npm ci
npm run dev
```

Run `npm run check` for lint, type-checking and a production build. The route tests in `tests/` expect a running site at `http://localhost:3100`.

## Deployment

The `main` branch is connected to the `christianbleeker-com` project in the Keyholders Agency Vercel team (`info-keyholdersas-projects`). The public website is `www.christianbleeker.com`; DNS is managed separately by Christian.

This repository contains only the personal portfolio application and its published assets. The original template's MIT license is retained in [LICENSE](LICENSE).
